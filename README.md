# My Contacts App - Design Patterns

UC-01: User Registration
User creates an account with name, email, password, and user type. (Builder Pattern, Factory Pattern)

UC-02: User Authentication
Registered user logs in using Basic authentication or OAuth. (Strategy Pattern, Singleton Pattern)

UC-03: User Profile Management
User updates profile details such as name, password, or preferences. (Command Pattern)

UC-04: Create Contact
User adds a new contact with name, phone numbers, and email addresses. (Builder Pattern, Factory Pattern)

UC-05: View Contact Details
User views formatted details of a specific contact. (Decorator Pattern)

UC-06: Edit Contact
User modifies existing contact information while preserving previous state. (Command Pattern, Memento Pattern)

UC-07: Delete Contact
User removes a contact and notifies related components. (Observer Pattern)

UC-08: Bulk Operations
User performs operations like delete or export on multiple contacts. (Composite Pattern)

UC-09: Search Contacts
User searches contacts by name, phone, or email. (Specification Pattern, Chain of Responsibility Pattern)

UC-10: Advanced Filtering
User applies multiple filters such as tag or date added. (Composite Pattern, Strategy Pattern)

UC-11: Create and Manage Tags
User creates reusable tags for organizing contacts. (Flyweight Pattern)

UC-12: Apply Tags to Contacts
User assigns or removes tags from contacts. (Observer Pattern)
